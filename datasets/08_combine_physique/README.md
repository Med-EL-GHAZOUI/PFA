# 08_combine_physique

**Description** : Mesures anthropometriques et physiques du draft combine (2000-2021) et liste de tous les choix de draft (1947-2020).

**Source** : GitHub josedv82/public_sport_science_datasets - dossier NBA Combine

**Lien(s)** : https://github.com/josedv82/public_sport_science_datasets/tree/main/NBA%20Combine

**Licence / usage** : Voir le depot ; donnees d'origine NBA draft combine.

**Comment le retelecharger** : scripts/03_download_github_datasets.py

## Fichiers

- `NBA_Combine_Anthro (2000-21).csv` - 1395 lignes, 11 colonnes, 0.1 Mo
- `NBA_Combine_Physical (2000-21).csv` - 1395 lignes, 9 colonnes, 0.1 Mo
- `NBA_History (1947-2020).csv` - 8083 lignes, 7 colonnes, 0.5 Mo

## Colonnes (exemple : `NBA_Combine_Anthro (2000-21).csv`)

`Season`, `PLAYER`, `POS`, `BODY FAT %`, `HAND LENGTH (inches)`, `HAND WIDTH (inches)`, `HEIGHT W/O SHOES`, `HEIGHT W/ SHOES`, `STANDING REACH`, `WEIGHT (LBS)`, `WINGSPAN`
