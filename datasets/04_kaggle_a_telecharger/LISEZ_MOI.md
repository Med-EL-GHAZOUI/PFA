# Datasets Kaggle (non telecharges : compte Kaggle requis)

Voir `scripts/02_download_kaggle.py` (instructions en tete du fichier) puis lancer :
    pip install kaggle && python scripts/02_download_kaggle.py

Les datasets 05 a 09 de ce dossier couvrent deja la plupart des besoins (tirs, blessures, physique) sans compte Kaggle ; Kaggle apporte surtout la base SQLite complete (`wyattowalsh/basketball`) et `Seasons_Stats.csv` depuis 1950.
