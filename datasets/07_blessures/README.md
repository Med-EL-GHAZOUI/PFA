# 07_blessures

**Description** : Blessures et absences de joueurs NBA (~2010-2020) avec date, equipe, joueur et nature de la blessure ; un fichier fusionne avec des stats de jeu.

**Source** : GitHub alexmjn/NBA-Injuries et Jecoc907/NBA-Player-Injuries-Analysis

**Lien(s)** : https://github.com/alexmjn/NBA-Injuries ; https://github.com/Jecoc907/NBA-Player-Injuries-Analysis

**Licence / usage** : Voir les depots.

**Comment le retelecharger** : scripts/03_download_github_datasets.py

## Fichiers

- `injuries_alexmjn.csv` - 9783 lignes, 5 colonnes, 0.6 Mo
- `Injuries_Jecoc907.csv` - 27105 lignes, 5 colonnes, 1.6 Mo
- `merged_Jecoc907.csv` - 5578 lignes, 32 colonnes, 0.8 Mo

## Colonnes (exemple : `injuries_alexmjn.csv`)

`Date`, `Team`, `Acquired`, `Relinquised`, `Notes`
